# Тая, с днём рождения — сайт-подарок

Это статический сайт: записка с извинением, «замок» со словом, письмо-поздравление, экран с обнимающимися котиками, галактика из слов «люблю» на разных языках и портрет из сердечек, который открывается свайпом по галактике. Никаких баз данных, PHP и установок не нужно.

## Что лежит внутри

```
index.html          — весь сайт: тексты, стили, сцены, проверка слова
assets/fonts.css    — подключение шрифтов
assets/fonts/*      — шрифты (Caveat, Cormorant Garamond, Golos Text), лежат локально
assets/galaxy.webp  — галактика из слов (готовая картинка)
assets/portrait.webp — портрет Таи из сердечек (готовый файл)
assets/og.jpg       — превью ссылки для Telegram / WhatsApp (1200×630)
assets/favicon.svg  — иконка сайта
README.md           — эта инструкция
```

Интернет для шрифтов и картинки не нужен: всё лежит рядом, сайт работает сам по себе.

## Как выложить на Beget

1. Зайдите в панель Beget → **Файлы** (файловый менеджер).
2. Откройте папку сайта. Обычно это `public_html` (или `ваш-домен/public_html`).
3. Загрузите туда **содержимое** этой папки: `index.html` и папку `assets`. Можно загрузить zip-архив и распаковать его прямо в файловом менеджере.
4. Проверьте, что `index.html` лежит **прямо в public_html**, а рядом — папка `assets` (не `public_html/site/index.html`).
5. Откройте сайт по адресу `https://ваш-домен.ru`.
6. В панели Beget включите **HTTPS** (Let's Encrypt), чтобы ссылка была с замочком.

Если на домене лежит старая заглушка Beget — удалите или переименуйте её `index.html`, чтобы открывался наш.

## Что и где менять

Почти всё меняется в `index.html` обычным текстовым редактором.

**Имя получательницы** — в начале скрипта, блок `CONFIG`:

```js
name: "Тая",
```

Оно подставится в «Тая, это тебе», в письмо и в заголовок страницы. Дополнительно поменяйте вручную:
- `<title>Тая, с днём рождения</title>`;
- `og:title` и `og:description` в `<head>`;
- по желанию — картинку `assets/og.jpg`.

**Записка до вопроса** — в секции `<!-- 0. ЗАПИСКА -->`: заголовок «Я не смог прийти», текст извинения и кнопка «дальше». Меняйте текст прямо там.

**Текст письма** — в секции `<!-- 2. ПИСЬМО -->`, между комментариями «ТЕКСТ ПИСЬМА — меняйте здесь». Заголовок карточки — `letter__title` («С днём рождения»).

**Котики и подпись «я люблю тебя»** — в секции `<!-- 3. КОТИКИ -->`: сама картинка, подпись `.cats__caption` и кнопка «дальше».

**Вопрос на замке** — строка:

```html
<p class="lock__question">где мы встретились впервые?</p>
```

**Подсказка** (появляется после двух неверных попыток):

```html
<p class="lock__hint" id="lock-hint">подсказка: там гаснет свет и пахнет кулисами</p>
```

**Какие ответы считаются правильными** — `CONFIG.keywords`:

```js
keywords: [
  "театр", "teatr", "theat",
  "драм", "сцен", "спектакл", "кулис", "занавес",
  "тюз", "мхат", "бдт",
  "кружок", "студи", "актер", "репетиц",
  "люблю", "любовь", "любим"
],
```

Правильным считается любой ответ, в котором встречается одно из этих слов. То есть проходят: «театр», «театральный», «театральный кружок», «театралка», «драмкружок», «на сцене», «в кулисах», «ТЮЗ», «МХАТ», «БДТ», «кружок», «студия», «актёр», «репетиция», «занавес». Слово «люблю» тоже открывает замок — маленький секрет.

Регистр, лишние пробелы, запятые и «ё» не важны: `ТЕАТР!`, `Театральный  кружок` и `театральныи кружок` тоже подойдут.

## Служебные ссылки

- `?reset=1` — сбросить старое сохранённое состояние от прошлой версии сайта (если она у вас открывалась) и увидеть замок.
- `?scene=letter` — сразу открыть письмо.
- `?scene=cats` — сразу открыть котиков.
- `?scene=galaxy` — сразу открыть галактику.

Пример: `https://ваш-домен.ru/?reset=1`.

Сайт каждый раз начинается с записки «прости, я не смог прийти» — так задумано. Дальше идёт вопрос, затем письмо, котики и галактика. Переходы плавные: записка и замок растворяются, а следующий экран проявляется.

## Превью ссылки в Telegram

Сейчас в `<head>` стоит относительный путь:

```html
<meta property="og:image" content="assets/og.jpg">
```

Telegram и VK надёжнее показывают превью с полным адресом. После загрузки на хостинг замените на:

```html
<meta property="og:image" content="https://ваш-домен.ru/assets/og.jpg">
```

И заодно проверьте `og:title` / `og:description`. Если превью не обновилось — отправьте ссылку в новый чат: мессенджеры кешируют старую картинку.

## Как проверить

1. Откройте сайт с телефона: сначала появится записка «прости, я не смог прийти». Нажмите «дальше».
2. Появится вопрос. Введите `театральный кружок` → откроется письмо-поздравление.
3. Нажмите «а теперь — дальше» → появятся котики с подписью «я люблю тебя».
4. Нажмите «дальше» → появится галактика.
5. Проведите пальцем вбок по галактике → проявится портрет Таи из сердечек. Ещё один свайп вбок — обратно к галактике.
6. Покрутите галактику пальцем (небольшие движения) — она вращается.

## Мелочи

- При разгадке звучит очень тихий колокольчик — он генерируется прямо в браузере, аудиофайлов нет. Если не нужен, удалите вызов `chime();` в обработчике формы.
- Галактика — заранее отрисованная картинка, поэтому телефон не тратит силы на тысячи слов.
- Портрет — тоже готовая картинка: фото заранее обработано, фон убран, а лицо собрано из тысяч сердечек. Исходное фото на сайте не хранится.
- Если нужно поменять фото: замените `assets/portrait.webp` на другой обработанный портрет с прозрачным фоном (пропорции 4:5, ширина 900 px). Обычное фото без обработки не подойдёт — его нужно так же превратить в сердечки (могу сделать).
- Сайт корректно смотрится и на компьютере, и на телефоне.
- Если что-то пошло не так, проще всего открыть консоль браузера (F12) и посмотреть ошибки — но при загрузке всех файлов из этой папки их быть не должно.
